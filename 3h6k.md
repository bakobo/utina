Three ways out, all Daniel's call: (1) keep the fixture and change the beat's expected value to pending/unresolved-conflict, which contrasts nicely with beats 18-19 — revocation reaches neither direction, duplicity poisons the voice going forward; (2) move the duplicity to the subject's signing position, which makes self-convicted correct and rhymes with Act IV's amendment convicted on its own bytes; (3) my reading is wrong, in which case the spec span to argue from is 1689-1694.

Two further things the build will need whichever way it goes. Conviction-grade at the governance tier requires the frame to have committed the violated predicate (:1683-1688), and Acme's law commits none — so the conviction has to be KEY-tier, under KERI's superseding-recovery calculus, which utina's fold cannot run because it imports no KERI library. The honest shape is a committed event recording that duplicity was observed, which the fold reads as evidence; that is a new event kind and a writer verb. And Q13 in docs/custos-questions.md already records that utina refuses a SAID collision rather than convicting on it, which is the adjacent decision and should be revisited with this one.
